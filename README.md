### **這是RunShootGame的玩法DEMO**
* 使用技術：
**1.Object Pooling降低資源使用以穩定FPS。**
**2.ScriptableObject實現動態成長與難度提升時不影響設定基礎值。**

### 遊戲主要功能 (Main Features)

1. **無盡生存與動態難度機制**
   * 玩家需要在場景中努力走位生存。隨著遊玩時間的拉長，遊戲會自動計算並啟動難度提升。
2. **二選一命運道具牆 (Item Wall System)**
   * 定期隨機產生「一對」互相綁定的魔法牆。玩家撞擊並穿過其中一道牆後會獲得該屬性，同時兩道牆會一起消失。
3. **動態武器成長系統**
   * 玩家在碰撞牆壁後，若玩家沒有該武器則發放新武器；若已有該武器則將其子彈等級 (Level) 做對應的加減，提供成長。
